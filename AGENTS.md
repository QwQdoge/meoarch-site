# MeoArch Site agent rules

This repository owns only the static umbrella website for MeoArch (`index.html`, `styles.css`, `app.js`, `assets/`).
The shared workspace rules in `../AGENTS.md` apply: work on `main` only, no feature branches or PRs.

- Do not copy product source (ISO, installer, MeoUI, MeoKDE) here; link to the product repositories instead.
- Keep product and download claims consistent with what is actually released and verified.
- For browser-facing changes, serve the repository over local HTTP and check desktop and phone widths in both languages.
- Do not publish, change DNS or alter hosting-provider configuration without explicit authorization.
