Lists, Rows and Sections

Lists are the workhorse of MeoUI pages. This page covers content lists (files, apps, messages); settings rows follow SETTINGS.md and share the same connected-surface engine.

1. Components

ComponentRole
MeoListViewThe scrolling container (transitions, scroll position)
MeoListItemA content row (headline, supporting text, leading/trailing parts)
MeoSegmentedList / MeoGroupedListConnected rounded group of rows
MeoSettingsRow + MeoSettingsGroupSettings rows with a typed trailing control
MeoListHeaderSection header above a group
MeoDividerQuiet separator when a connected surface is not used
MeoSwipeToDismissSwipe actions on touch
MeoDataTableDense, sortable tabular data on wide windows

2. Anatomy of a row

[leading]  Overline                         [trailing]
           Headline
           Supporting text (1–3 lines)

MeoListItem properties: overline, headline, supportingText, supportingTextLines (1, 2 or 3), leadingIcon, leadingImage (leadingImageVariant square or circle, leadingImageSize 40 / 56 / 64), leadingComponent, trailingComponent, badgeText, actions, selected, interactive.

PartRule
LeadingOne of: icon, avatar (40), small image (56), large image (64). Same kind in a list
HeadlineThe identity of the row; one line, elided
SupportingThe one fact that helps decide (version, size, date). ≤3 lines
TrailingOne control or one status: a value, a switch, a chevron, an action. Not several
BadgebadgeText for count/new; a dot for unread

Height follows content: 56dp one line, 72dp two lines, 88dp three lines; isDense gives 48 / 64 / 72dp. A large leading image raises the height.

3. Choose the row style

NeedProperty
Separate rows with lines on a flat pageshowDivider: true, dividerInset to align with text
Rounded connected group (default for ≤ ~15 rows)isSegmented: true, set roundingStrategy (top, middle, bottom, all) per position, or use MeoSegmentedList
Dense list (file manager, logs)isDense: true
Emphasize a key rowisEmphasized: true (bold)
Selected rowselected: true; vibrant selection with vibrant: true

Do not mix segmented rows and divider rows in one list. A long, virtualized list (hundreds of rows) uses divider rows; connected groups are for short sets.

4. Behavior

  • A row is either interactive as a whole or contains controls. If it has a trailing switch, the whole row toggles it (as MeoSettingsRow does); if it has a trailing action button, the row body opens details.
  • Selection: tap/click selects; in multi-select mode the leading element becomes a checkbox and the top app bar turns contextual (NAVIGATION.md).
  • Swipe actions are a shortcut for touch; the same actions exist in a context menu (MeoContextMenu) and the row's detail.
  • Reordering and removal animate with MeoListTransitions; Reduce Motion makes them instant.
  • Right-click / long-press opens MeoContextMenu with the row's actions.

5. Sections and headers

  • MeoListHeader { text: ... } names a group; type: "emphasized" for the first section on a page.
  • A header describes what the rows are ("Updates (3)"), not what to do.
  • A section with more rows than fit shows a "See all" text button in the header row, not a row at the end.
  • Empty section: hide the header unless the empty state needs it (STATES.md).

6. Tables

Use MeoDataTable when the user compares columns or sorts (package list with name, version, size, source). On compact windows a table becomes a list with the most important column as the headline.

  • Header row sticky; click sorts; arrow icon shows direction.
  • Right-align numbers, left-align text.
  • Never let the table scroll horizontally on expanded windows; hide the least important columns first.

7. Long lists and loading

  • Virtualize: use ListView models; never create a row per item in a Column.
  • First load: MeoSkeleton rows with the final row height (MeoLoadingFeedback { placeholder }).
  • Loading more: a single row at the end with MeoLoadingIndicator, not a full skeleton.
  • Refresh: keep old rows until new data arrives; update in place.
  • Empty: MeoEmptyState. Error: inline message with Retry (STATES.md).

8. Example

import QtQuick
import MeoUI

MeoListView {
    id: updates
    model: updatesModel
    delegate: MeoListItem {
        required property var model
        width: ListView.view.width
        headline: model.name
        supportingText: qsTr("%1 → %2 · %3").arg(model.current).arg(model.next).arg(model.size)
        leadingImage: model.icon
        leadingImageSize: 40
        leadingImageVariant: "circle"
        badgeText: model.security ? qsTr("Security") : ""
        showDivider: true
        onClicked: openDetails(model.id)
    }
}

Property names come from MeoListItem and MeoListView; the snippet has not been run in this pass.

9. Checklist

  • ☐ Rows have one leading kind and ≤1 trailing element.
  • ☐ Whole-row action and inner controls do not conflict.
  • ☐ Virtualized; skeleton rows match final height.
  • ☐ Headers describe content; "See all" in the header.
  • ☐ Context menu and keyboard (Enter, Space, Delete) equal to swipe.
  • ☐ Text scale 200% and long translations tested.
