This is the agent-oriented version of the MeoUI specification. It says the same things as the human pages, in decision tables and checklists. When this file and another MeoUI document disagree, the other document wins and this file is a bug.

Source: MeoUI/docs/design/. Published: https://meoarch.org/docs/meoui/. Index for agents: https://meoarch.org/llms.txt.

Before you edit

  1. Read the target repository's AGENTS.md; its owner workflow rules come first.
  2. Identify which repository owns the change:
The change is aboutImplement it in
A reusable control, token, motion, layout or patternMeoUI
Plasma, KWin, D-Bus, panels, lock screen, title bar colorsmeo-kde
A system setting and its backendMeoSettings
One application's own flow or preferenceThat application's repository
ISO composition, installer, repair, AI routerMeoArch-os-workspace
  1. Read only the documents you need:
TaskRead
Window, toolbar, overflow menu, app settings, About, creditsAPP_SHELL.md
Any Settings-style page or rowSETTINGS.md, PAGE_TYPES.md
Colors, themingDYNAMIC_COLOR.md
Adding, replacing, deprecating or deleting public QML../api-lifecycle.md
Strings, translations, accessible names../localization.md

Hard rules (MUST / MUST NOT)

  • MUST import MeoUI 1.0; MUST NOT copy a MeoUI control into an app.
  • MUST use MeoTheme tokens and MeoTheme.globalScale; MUST NOT hard-code a color, dp size, radius, duration or easing that has a token.
  • MUST NOT create a product-local color palette.
  • MUST NOT use Qt.FramelessWindowHint on an application window.
  • MUST wrap every visible string and accessible name in qsTr(); MUST NOT use translated text as a key or stored value.
  • MUST NOT ship placeholder system facts; read the authoritative backend or show unknown.
  • MUST NOT put a system-wide control inside an app; link to Meo Settings.
  • MUST NOT hard-code an open-source credit list in QML; read the installed THIRD_PARTY_NOTICES.md.
  • MUST NOT select a deprecated component for new work; MUST NOT reintroduce a type listed in the docs/api-lifecycle.md removal record.
  • MUST NOT claim a validation level you did not run.

Decision table: desktop input (pointer and keyboard)

MeoUI keeps the Pixel / Material 3 Expressive look on every device; on desktop it adopts the input conventions shared by WinUI 3 and macOS.

QuestionAnswer
When does a focus ring showOnly in keyboard modality (MeoTheme.focusVisible, driven by MeoInputModality): Tab/arrow navigation shows it, a mouse/touch press that moves focus does not. Pass focused: <item>.activeFocus to MeoStateLayer; it applies the gate. Do not add a second focus ring
Hover feedbackColor only, through the state layer. No hover scale or lift (only the opt-in "playful" motion profile keeps one); press scale and active lift remain
Icon-only button labelSet MeoIconButton.toolTipText; it becomes the accessible name and a hover tooltip after MeoTheme.tooltipShowDelay (500 ms), never on touch
Tooltip timingMeoTooltip defaults to MeoTheme.tooltipShowDelay; do not hard-code a delay
ScrollbarMeoScrollBar: thin overlay pill while scrolling, full 8dp thumb plus faint track on hover/drag
Touch-specific behaviorBranch on MeoTheme.touchInput / MeoTheme.pointerType, never on Qt.platform.os

Decision table: accessibility and density

SettingContract
Text sizeMeoTheme.fontScale (0.5-3). Component text uses MeoTheme.textScale (globalScale * fontScale), never globalScale alone; icons and containers use globalScale
Reduce motion / motion speedMeoTheme.reduceMotion, MeoTheme.motionScale; all durations come from motion tokens, springs check reduceMotion
Reduce transparencyMeoTheme.transparencyEnabled; translucent surfaces take their alpha from MeoTheme.surfaceAlpha(a) (opaque when off). Shell blur-behind follows the same flag
Increase contrastMeoTheme.highContrast: secondary text uses on-surface, outlines/dividers strengthen, state layers +4%, focus ring +1dp
DensityMeoTheme.density 0/-1/-2/-3 (M3 density scale, 4dp per step, per-component floors); resolves to 0 on touch input. Heights come from MeoTheme.buttonHeightForSize(), densityAdjusted() and minimumTargetSize
IconsMeoIcon (Material Symbols Rounded, one shared font loader via MeoTheme.iconFontFamily). Optical size follows the drawn size (20-48); grade follows MeoTheme.iconGrade (-25 dark, 200 high contrast). Override axes only for a deliberate emphasis
Who sets themThe host (meo-kde, apps) binds them to the platform settings; components only read MeoTheme

Decision table: rendering and motion performance

QuestionAnswer
Drive a per-frame sampled motion (spring, morph)FrameAnimation (vsync-aligned) via MeoSpringValue; never a 16 ms Timer, which drops/doubles frames at 60 Hz and caps high-refresh panels at ~60 Hz
Draw a rect / pill / circle surfaceMeoShape (scene-graph Rectangle for rect, round, squircle, circle); Canvas only for the expressive shape catalog
Draw an animated arc, spinner or morphing pathQtQuick.Shapes (Shape.CurveRenderer); never an animated Canvas, which re-rasterizes on the CPU and re-uploads a texture every frame
Rotate a drawn shapeAn item rotation transform, not a repaint
Elevation shadowMeoElevationShadow { target: surface; elevation: MeoTheme.elevationLevelN } as a sibling behind the surface; never hand-write MultiEffect shadow values, and never put layer.enabled on an item that contains a state layer, ripple, spinner or other animated content
Which levelM3 component levels: buttons/cards 1 (hover 2), menus/rich tooltips/pull-to-refresh 2, dialogs/snackbars/floating toolbars/popovers 3, FAB by its token; values between levels interpolate. Elevation tokens are already scaled, so do not multiply by globalScale again
Fade an overlay outGate visible on the animated opacity (visible: opacity > 0), not on the condition that drives it; otherwise the exit transition never renders. Items inside a Row/Layout may hide immediately instead
Infinite or decorative animationrunning includes visible (and !MeoTheme.reduceMotion when it moves)
Shape-pair results (topology alignment, interpolation tables)Compute once per pair and cache; never per frame

Validation (MeoUI repository)

Run the narrowest check that covers the change:

# static design-system usage
python3 tools/verify-design-system-usage.py --mode library MeoTheme.qml MeoMotion.qml components widgets patterns
# normal QML/C++ change
cmake --fresh -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo -DBUILD_TESTING=ON -DMEOUI_BUILD_SHOWCASE=OFF
cmake --build build --parallel 2
QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure --timeout 60
# public QML export or catalog change
python3 tools/verify-showcase-coverage.py

Docs-only changes need no build. After changing anything in docs/design/, regenerate the site with python3 scripts/build_docs.py in meoarch-site.

Reporting

State which evidence level you reached: static, offscreen, Showcase runtime, or manual visual. Name what was not verified.
