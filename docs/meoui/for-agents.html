This is the agent-oriented version of the MeoUI specification. It says the same things as the human pages, in decision tables and checklists. When this file and another MeoUI document disagree, the other document wins and this file is a bug.

Source: MeoUI/docs/design/. Published: https://meoarch.org/docs/meoui/. Index for agents: https://meoarch.org/llms.txt.

Before you edit

  1. Read the target repository's AGENTS.md; its owner workflow rules come first.
  2. Identify which repository owns the change:
The change is aboutImplement it in
A reusable control, token, motion, layout or patternMeoUI
Plasma, KWin, D-Bus, panels, lock screen, title bar colorsmeo-kde
A system setting and its backendMeoSettings
One application's own flow or preferenceThat application's repository
ISO composition, installer, repair, AI routerMeoArch-os-workspace
  1. Read only the documents you need:
TaskRead
Window, toolbar, overflow menu, app settings, About, creditsAPP_SHELL.md
Any Settings-style page or rowSETTINGS.md, PAGE_TYPES.md
Colors, themingDYNAMIC_COLOR.md
Adding, replacing, deprecating or deleting public QML../api-lifecycle.md
Strings, translations, accessible names../localization.md

Hard rules (MUST / MUST NOT)

  • MUST import MeoUI 1.0; MUST NOT copy a MeoUI control into an app.
  • MUST use MeoTheme tokens and MeoTheme.globalScale; MUST NOT hard-code a color, dp size, radius, duration or easing that has a token.
  • MUST NOT create a product-local color palette.
  • MUST NOT use Qt.FramelessWindowHint on an application window.
  • MUST wrap every visible string and accessible name in qsTr(); MUST NOT use translated text as a key or stored value.
  • MUST NOT ship placeholder system facts; read the authoritative backend or show unknown.
  • MUST NOT put a system-wide control inside an app; link to Meo Settings.
  • MUST NOT hard-code an open-source credit list in QML; read the installed THIRD_PARTY_NOTICES.md.
  • MUST NOT select a deprecated component (for example MeoBottomAppBar) for new work.
  • MUST NOT claim a validation level you did not run.

Validation (MeoUI repository)

Run the narrowest check that covers the change:

# static design-system usage
python3 tools/verify-design-system-usage.py --mode library MeoTheme.qml MeoMotion.qml components widgets patterns
# normal QML/C++ change
cmake --fresh -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo -DBUILD_TESTING=ON -DMEOUI_BUILD_SHOWCASE=OFF
cmake --build build --parallel 2
QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure --timeout 60
# public QML export or catalog change
python3 tools/verify-showcase-coverage.py

Docs-only changes need no build. After changing anything in docs/design/, regenerate the site with python3 scripts/build_docs.py in meoarch-site.

Reporting

State which evidence level you reached: static, offscreen, Showcase runtime, or manual visual. Name what was not verified.
