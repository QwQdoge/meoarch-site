Meo Account

本页

  • 你能做什么
  • 安全
  • 隐私与条款
  • 开发者

Meo Account 是 MeoArch 的账号：一个账号登录 Meo AI、备份设置，并在你的设备之间共享账号里的模型连接。账号页面在 account.meoarch.org，接口在 api.meoarch.org。

你能做什么

  • 用邮箱和密码、Google、GitHub 或通行密钥登录；这些是同一个账号的不同登录方式。社交账号只有在提供商明确报告邮箱已验证时才被视为已验证；两个身份不会仅因邮箱相同就被合并。
  • 查看和修改资料、偏好。
  • 查看当前的登录会话，注销某个会话、其他所有会话或全部会话。
  • 查看自己的安全记录。
  • 保存最多 20 份云端备份（设置清单），下载或删除。
  • 管理账号里的模型连接（提供商密钥加密保存，不会返回给客户端）。
  • 导出自己的账号数据；删除账号。

安全

  • 敏感操作（改密码、改邮箱、删除账号、两步验证等）要先“重新验证身份”，授权只对一个用途有效，10 分钟内可用。普通登录不等于重新验证。
  • 改主邮箱分两步：新邮箱验证之前，原邮箱继续有效，并会收到通知。
  • 新账号需要完成一次人机验证。
  • 桌面应用拿不到你的令牌：见 原生应用接入。

隐私与条款

账号和 Meo AI 保存什么、谁会收到数据、保存多久，见 隐私政策；使用条款见 服务条款。

开发者

  • Meo Account API：登录、令牌、流式对话、错误码、方案与额度、备份格式。
  • Meo API 参考：全部对应用开放的接口。
  • 原生应用接入：桌面应用怎么用账号。
