# MeoArch

MeoArch 是一个基于 Arch Linux 的桌面系统。

## 名字的意思

MEO = Modern · Expressive · Open：交互和呈现要现代，动效和视觉语言要有表现力，Linux 的基础和用户的控制权要保持开放。Arch 指它建立在 Arch Linux 之上。

## 它想做什么

让 Linux 更容易理解，同时不拿走它的自由。

- 每件事都有图形界面，设置会解释自己。
- 高风险修改可以预览，出问题可以恢复。
- 底层仍然是真正的 Linux，进阶用户依然可以直接查看服务、配置和日志。

## 为什么是 Arch

因为自由和新：滚动更新让软件保持较新，也不替你做决定。MeoArch 在这份自由之上，加一层更容易理解、更容易恢复的操作界面。

## 现在的状态

仍在公开开发中，目前只有测试版。请先在虚拟机或备用设备上试用，并备份重要数据。使用前的条件见 [使用要求](requirements.md)。
